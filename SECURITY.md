# Сообщение о проблеме

Для сообщения о возможном выходе из каталога данных, изменении исходной базы, обходе ограничения SQL или раскрытии строк подготовьте минимальный пример на синтетических данных. Не помещайте секреты и рабочие записи в публичный issue.

Если проблема содержит чувствительные детали, сначала свяжитесь с владельцем репозитория приватным способом. Отдельный сервис приёма уязвимостей и гарантия времени ответа для этого исследовательского прототипа не установлены.

Сервер предназначен для локального запуска доверенным пользователем. Он не является многопользовательским сервисом, не аутентифицирует сетевые подключения и не предоставляет изоляцию операционной системы для враждебных файлов SQLite. Рабочие данные должны поступать из разрешённого и доверенного источника.
